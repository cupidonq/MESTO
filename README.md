# MESTO

Учёт для малого бизнеса: **кабинет владельца**, **приложение кассира** (работает без интернета) и сервер. Продажи, товары, сотрудники, смены, расходы и финансы.

> Это готовая сборка. **Исходный код закрыт** и в репозиторий не входит. Лицензия — [LICENSE](LICENSE).
> Приложение кассира — учётный интерфейс, а не сертифицированная фискальная касса.

## Windows: установщик

На вкладке **Releases** лежит `MESTO-Setup-<версия>.exe`: установите и запускайте ярлык MESTO. Внутри всё нужное, интернет после установки не требуется.

## Запустить за один клик (из папки)

1. Скачайте репозиторий: кнопка **Code → Download ZIP** (или `git clone`) и распакуйте.
2. **Windows:** дважды щёлкните **`Start-MESTO.bat`**.
   **macOS / Linux:** в терминале `bash start-mesto.sh`.
3. Подождите 1–3 минуты при первом запуске. Откроется браузер: кабинет владельца `http://localhost:8080`, приложение кассира `http://localhost:8081`.

Больше ничего ставить не нужно: если на компьютере нет Node.js, программа сама скачает портативную версию с nodejs.org (проверяет контрольную сумму, ничего не устанавливает в систему, права администратора не нужны). Нужен только интернет при первом запуске. Данные хранятся в папке `data` рядом с программой.


## Безопасность

- В репозитории нет ключей, паролей и токенов. Секреты каждая установка создаёт у себя и хранит только локально (`data/`, `.env.production`); эти файлы в `.gitignore`.
