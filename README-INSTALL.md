# MESTO — установка

Это готовая версия MESTO: кабинет владельца, приложение кассира (работает без интернета) и сервер. Исходный код в поставку не входит.

## Быстрый запуск на своём компьютере (один щелчок, без Docker)

1. Распакуйте архив (или скачайте репозиторий кнопкой **Code → Download ZIP** и распакуйте).
2. Дважды щёлкните **`Start-MESTO.bat`** (macOS/Linux: `bash start-mesto.sh`).
3. Первый запуск скачивает всё нужное (1–3 минуты, нужен интернет). Потом откроется браузер с кабинетом владельца: `http://localhost:8080`. Приложение кассира — `http://localhost:8081`.

**Node.js ставить не нужно.** Если его нет, программа сама скачает портативную версию с nodejs.org (проверяет контрольную сумму SHA-256, в систему ничего не устанавливает, права администратора не нужны). Windows может показать предупреждение SmartScreen для .bat-файла: нажмите «Подробнее → Выполнить в любом случае».

Всё хранится в папке `data` рядом с программой, внешняя база не нужна. Окно не закрывайте, пока работаете; Ctrl+C или закрытие окна останавливает MESTO. Чтобы сохранить данные, копируйте папку `data` при остановленной программе.

Так запускается один компьютер для знакомства или работы одной точки. Доступ — только с этого компьютера.

### Бот Telegram: подтверждение аккаунтов и оплата

Без бота MESTO работает свободно: подтверждения и оплаты нет. Чтобы включить подтверждение аккаунтов кодом из Telegram и **оплату доступа Telegram Stars**:

1. Создайте бота у **@BotFather** (`/newbot`) и скопируйте токен.
2. Сохраните токен в файл `data/bot-token.txt` (папка `data` появляется после первого запуска) и перезапустите `Start-MESTO.bat`. Токен не отправляйте никому: это пароль от бота.
3. Бот заработает сам, публичный адрес не нужен.

**Оплата:** 1 ★ = 1 день, минимум 14 дней. Владелец оплачивает в кабинете («Подписка») или командой бота `/pay 30`. Пока доступ не оплачен, кабинет показывает только экран оплаты, а касса не теряет чеки: они отправятся, как только появится связь.

### Если не запускается

Журнал базы данных: `data/database.log`. Частые причины:

- **Кириллица в пути** (например, имя пользователя Windows на русском). Это обрабатывается автоматически: база хранится в `C:UsersPublicMESTO...`. Если всё равно ошибка, перенесите папку в `C:MESTO`.
- **Запуск от имени администратора.** PostgreSQL так не работает: запускайте обычным двойным щелчком.
- **Нет «Microsoft Visual C++ Redistributable»** (чистая Windows): установите https://aka.ms/vs/17/release/vc_redist.x64.exe и повторите.
- **Антивирус заблокировал postgres.exe:** добавьте папку MESTO в исключения.
- **Окно закрыли аварийно, и MESTO не стартует:** закройте оставшиеся окна MESTO или перезагрузите компьютер.
- Если данных ещё нет, а база сломана: удалите папку `data` (и `C:UsersPublicMESTO`, если она есть) и запустите заново.
