# MESTO — установка

Это готовая версия MESTO: кабинет владельца, приложение кассира (работает без интернета) и сервер. Исходный код в поставку не входит.

## Быстрый запуск на своём компьютере (один щелчок, без Docker)

1. Распакуйте архив (или скачайте репозиторий кнопкой **Code → Download ZIP** и распакуйте).
2. Дважды щёлкните **`Start-MESTO.bat`** (macOS/Linux: `bash start-mesto.sh`).
3. Первый запуск скачивает всё нужное (1–3 минуты, нужен интернет). Потом откроется браузер с кабинетом владельца: `http://localhost:8080`. Приложение кассира — `http://localhost:8081`.

**Node.js ставить не нужно.** Если его нет, программа сама скачает портативную версию с nodejs.org (проверяет контрольную сумму SHA-256, в систему ничего не устанавливает, права администратора не нужны). Windows может показать предупреждение SmartScreen для .bat-файла: нажмите «Подробнее → Выполнить в любом случае».

Всё хранится в папке `data` рядом с программой, внешняя база не нужна. Окно не закрывайте, пока работаете; Ctrl+C или закрытие окна останавливает MESTO. Чтобы сохранить данные, копируйте папку `data` при остановленной программе.

Так запускается один компьютер для знакомства или работы одной точки. Доступ — только с этого компьютера.
